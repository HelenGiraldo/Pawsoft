# ADR-07: Integración y Despliegue Continuo (CI/CD)

## Estado
Aceptado

## Contexto
Se requiere automatizar pruebas y despliegues para mantener calidad y eficiencia.

## Decisión
Se implementará un pipeline básico de CI/CD (por ejemplo, con GitHub Actions).

## Alternativas
- Despliegue manual.
- No usar integración continua.

## Justificación
Automatiza pruebas y reduce errores humanos.

## Consecuencias
- Configuración inicial adicional.
- Mayor confiabilidad en despliegues.
