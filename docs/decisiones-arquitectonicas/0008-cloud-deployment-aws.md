# ADR-08: Despliegue en Nube Pública (AWS)

## Estado
Aceptado

## Contexto
El proyecto requiere un entorno de despliegue real en nube pública para simular condiciones de producción.

## Decisión
Desplegar la aplicación en Amazon Web Services (AWS), utilizando servicios de cómputo y almacenamiento como Amazon S3.

## Alternativas
- Despliegue en Microsoft Azure.
- Despliegue en Google Cloud.
- Despliegue local.

## Justificación
AWS ofrece alta disponibilidad, escalabilidad y un nivel gratuito suficiente para el entorno académico.

## Consecuencias
- Dependencia del proveedor de nube.
- Necesidad de controlar recursos para evitar costos adicionales.
