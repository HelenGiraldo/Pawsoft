# ADR-04: Patrón de Diseño

## Estado
Aceptado

## Contexto
Se requiere mantener una organización clara del código y separación de responsabilidades.

## Decisión
Se utilizará el patrón MVC (Model-View-Controller).

## Alternativas
- Arquitectura sin patrón definido.
- Patrón basado en microservicios.

## Justificación
MVC facilita organización del código y claridad estructural en aplicaciones web.

## Consecuencias
- Código más mantenible.
- Requiere disciplina en la separación de responsabilidades.
