# ADR-06: Estrategia de Testing

## Estado
Aceptado

## Contexto
Es necesario validar el correcto funcionamiento del sistema y prevenir errores futuros.

## Decisión
Se implementarán pruebas unitarias y pruebas de integración.

## Alternativas
- Solo pruebas manuales.
- No implementar pruebas automatizadas.

## Justificación
Las pruebas automatizadas aumentan la confiabilidad y reducen errores en producción.

## Consecuencias
- Mayor tiempo de desarrollo inicial.
- Código más robusto y mantenible.
